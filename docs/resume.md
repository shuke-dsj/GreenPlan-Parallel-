# 简历项目表述

## 建议项目名

多工厂低碳生产计划的多目标并行优化（C++17 / OpenMP / MPI）

## 当前可直接使用的版本

- 将并行计算课程研究重构为生产计划优化项目，建立包含工厂产能、产品兼容性和市场需求的合成场景，同时优化利润、产能利用率和碳排放。
- 实现 NSGA-III 启发式多目标进化核心，组合非支配排序、参考方向关联和可行性修复；统一 Serial、OpenMP、MPI 评估接口，并提供 MSVC PPL 后端。
- 使用 MPI_Gatherv 处理种群不整除进程数的结果汇总；在 19 个体 / 3 进程测试中实现与串行结果逐字节一致，并验证 OpenMP 一致性和固定种子可复现性。
- 构建命令行实验入口、CSV 基准脚本、模型测试及跨平台 CI 配置；通过实测识别串行进化与选择瓶颈，避免以线程数推断实际加速收益。

## 面试时说明

这是独立课程项目工程化重构，业务数据为合成数据，尚无企业部署。
当前新实现没有证明显著的整体性能提升。PPL 本机未验证，CI 未运行前不声称全平台测试通过。
旧论文的 9.13 倍/3.01 倍需要复现实验支持，不能移植成新版本指标。

## 后续获得证据后才能加入的指标

实际稳定加速比、并行效率、支持的最大规模、HV/IGD 改进值、真实生产数据上的收益。
每个指标应能追溯到代码提交、硬件配置、命令行、种子和原始 CSV。
