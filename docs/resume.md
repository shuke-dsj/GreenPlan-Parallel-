# 简历项目表述

## 项目名称

多工厂低碳生产布局与产能分配优化｜C++17 · OpenMP · MPI · PPL

## 简历版本

面向制造企业跨工厂生产规划场景，构建多目标优化原型，探索产能分配、产能利用率与碳排放之间的权衡。项目基于合成数据验证，输出可供比较的 Pareto 方案指标。

- 将生产决策建模为“工厂 × 月份 × 产品”的连续产量，结合工厂产能、产品兼容性和跨工厂共享的月度需求，计算利润、产能利用率及生产碳排放三项指标。
- 实现 NSGA-III 启发式进化流程，结合非支配排序、参考方向关联与可行性修复，生成兼顾多个业务目标的候选方案。
- 建立串行、OpenMP、MPI 和 Windows PPL 共用的个体评估接口；使用 `MPI_Gatherv` 汇总不等长进程分区，验证 19 个个体、3 个进程场景下与串行结果一致。
- 编写模型不变量测试、固定种子一致性检查和基准脚本；Linux OpenMP/MPI 与 Windows OpenMP/PPL 已通过 GitHub Actions 验证，并通过基准识别串行进化与选择阶段的性能瓶颈。

## 面试展开

**业务问题。** 多工厂如何在产能与产品适配约束下安排各月产量，并展示利润、产能利用率和碳排放的折中关系？模型以单个产品、单个月份的所有工厂产量之和与需求比较，避免重复计算各工厂的销量。

**技术方案。** 决策变量为连续产量，先修复不兼容和超产能方案，再用非支配排序和参考方向选择保留不同权衡的候选个体。所有后端调用相同的确定性评估函数；随机初始化和遗传操作由主线程或 MPI 根进程集中执行。

**验证证据。** 19 个个体、3 个 MPI 进程的非整除分区测试通过；固定种子下，测试范围内 MPI、OpenMP 和 PPL 的目标 CSV 与串行结果逐字节一致。测试结果见 [CI 运行记录](https://github.com/shuke-dsj/GreenPlan-Parallel-/actions/runs/44057207682)。

**结果与边界。** 目前使用合成数据，没有企业部署或真实业务收益数据；输出是非支配方案的目标指标，尚不输出完整逐工厂月产品决策表。该模型处理既有工厂之间的产量分配，不包含工厂选址、产线安装或车间工序排序。当前小规模基准未证明显著整体加速。

**算法表述。** 实现借鉴 NSGA-III 的参考方向选择，并采用算术交叉与稀疏扰动；未实现标准 NSGA-III 的极值点/截距归一化及完整随机 niching，不应称为标准算法的完整复现。

## 可补充的结果指标
