# 生产计划模型

工厂集合 F={0..4}、产品集合 P={0..7}、月份集合 T={0..M-1}。
变量 x[f,t,p] 是连续产量。它不表示工序顺序或机器占用，因此项目归类为生产计划优化。

工厂产能 C[f]=1000*(0.8+0.1*f)。当 (f+p)%4==0 时不兼容。
单位售价、成本和排放系数在 src/main.cpp 显式定义，不来自企业采集数据。
月需求 D[t,p]=420+40*p+60*sin(2*pi*t/12)。需求按产品月聚合，所有工厂共享。

令 Q[t,p]=sum_f x[f,t,p]，优化目标为：

1. 利润最大：sum_(t,p) price[p]*min(Q[t,p],D[t,p])-cost[p]*Q[t,p]。
2. 利用率最大：sum_(f,t,p) x[f,t,p] / sum_(f,t) C[f]。
3. 排放最小：sum_(t,p) carbon[p]*Q[t,p]。

代码统一转换成最小化向量 (-profit,-utilization,carbon)。

约束为 x>=0、不兼容时 x=0、每个工厂月总量 <= C[f]。
修复先截断负产量并清空不兼容项，再按比例压缩超产能的工厂月分组。
目前没有把需求作为硬约束：过量部分不产生销售收入，但仍承担成本和排放。

利润、利用率和排放通常冲突，但低需求/特殊参数可能使某些目标近似冗余。
利用率高不等于资源效率高，本项目不宣称单位资源产出最优。

算法先对种群做非支配排序，再按归一化目标与参考方向的垂直距离关联。
完整前沿全部保留；截断前沿优先选占用少的方向，并按距离和索引确定性打破平局。
这是 NSGA-III 启发式策略，不等价于 Deb/Jain 的完整标准算法。

每个子代用锦标赛选父本，逐变量算术交叉，并以 1/维数 概率施加有界幅度扰动。
初始化和遗传操作只在根进程/主线程执行，评估是纯确定性函数。
保持同一输入与随机种子时，串行和各后端应输出同一目标集。

当前 CSV 只导出非支配计划的目标指标，尚不导出完整逐工厂月产品决策表。
它适用于算法实验与方案对比；完整计划解释和排程可执行性仍需扩展。
