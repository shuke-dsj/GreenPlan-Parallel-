# 工程化记录

本项目继承原课程作业的“生产计划多目标优化 + 并行计算”问题方向，采用独立的新代码实现。
原作业的 PDF、DOCX、旧可执行文件和含个人学号的封面不包含在公开项目中。

| 原作业特征 | 当前工程 |
|---|---|
| 三份独立实现，算法和计时口径容易漂移 | 一个核心，四种评估后端 |
| Windows 专用随机和运行时接口 | 标准 C++17 核心，按平台编译后端 |
| 多层线程团队与共享 RNG 风险 | 只并行纯评估函数，随机操作保持集中 |
| MPI 余数划分搭配固定 Gather | Gatherv 的 counts/displacements 与分区一致 |
| 参数主要通过宏修改 | CLI 控制种群、代数、时间跨度、后端、种子 |
| clock() 与复杂模块累计统计 | steady_clock 墙钟时间与结构化 CSV |
| 需求在单工厂/生产线内重复计入风险 | 全工厂共享的产品月需求 |
| 历史加速数字与指标混用 | 新数据单独测量，明确 S=T1/Tp、E=S/p |

新实现主动缩小模型复杂度：保留 5 工厂、8 产品、多月与三种硬约束，没有声称实现原论文全部六类约束。
新进化策略也不沿用旧代码的全部算子；完整说明见 model.md。

## 性能解释

docs/benchmark-local.csv 是实际本机运行数据，不是论文表格转录。
总时间包含初始化、进化、评估、选择以及结果 CSV 写出；不含程序启动和 MPI_Init。
evaluation_seconds 只累计每代子代评估，未包含初始种群评估。
MPI 评估时间包含广播和收集，因此不应解释成纯计算时间。
OpenMP 总耗时几乎不变，符合当前评估函数较轻、主要工作仍串行的设计。
基准数据暂未固定核心亲和性、没有预热轮次，短任务噪声明显；后续严谨性能论文需要补充实验控制。

## 风险与下一步

排序是 O(N^2)，参考方向选择集中执行；MPI 每代广播全部决策数据，规模大时会有复制与根进程瓶颈。
需增加标准 NSGA-III 对照、HV/IGD 指标和小实例最优性对照，再讨论搜索质量。
不应将一致性测试解读为算法最优性证明，也不应将历史论文提速写入新工程的简历。
