### [GreenPlan Parallel · 多工厂低碳生产计划优化](https://github.com/shuke-dsj/GreenPlan-Parallel-)

使用 C++17 将生产计划中的利润、产能利用率与碳排放建模为多目标问题，采用 NSGA-III 启发式进化与约束修复，探索 Serial / OpenMP / MPI / PPL 的并行评估策略。

实现固定种子可复现、MPI 不等长分区汇总与串并行结果一致性验证，提供命令行、CSV 实验数据及跨平台持续验证配置。源于课程研究，使用合成业务场景，重点展示优化建模、并行正确性和性能分析能力。

技术：C++17 · OpenMP · MPI · PPL · CMake · GitHub Actions
